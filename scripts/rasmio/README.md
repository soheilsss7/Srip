# ربات استخراج گراف رسمیو (Rasmio Capture)

رباتی که با حساب کاربری خودِ مالک (شمارهٔ موبایل در Secret گیت‌هاب) وارد رسمیو
می‌شود، گراف ارتباطات شرکت‌های خواسته‌شده را استخراج می‌کند و خروجی را به‌صورت
artifact تحویل می‌دهد تا وارد سامانهٔ SRIP شود.

## اجزا

| فایل | نقش |
|---|---|
| `capture.mjs` | خودِ ربات (puppeteer) — ورود با کد پیامکی + گردش شرکت‌ها + ضبط JSON گراف |
| `companies.json` | فهرست شرکت‌ها: `[{"name":"نام شرکت","nationalId":"شناسهٔ ملی"}]` |
| `otp.txt` | (نمی‌کامیت) جایی که عامل Arena کد پیامکی کاربر را وسط اجرا می‌نویسد |
| `../../.github/workflows/rasmio-sync.yml` | اجراکننده روی GitHub Actions |

## Secret لازم (فقط یکی)

`RASMIO_PHONE` = شمارهٔ موبایل یا ایمیل حساب رسمیو.
مسیر: Settings → Secrets and variables → Actions → New repository secret.
**رمز/کدی در Secret نیست** — رسمیو هر بار کد پیامکی می‌فرستد.

## جریان اجرا (بدون دخالت فنی کاربر)

1. عامل Arena اجرا می‌کند: `gh workflow run rasmio-sync.yml --ref <branch>`
2. ربات شماره را وارد رسمیو می‌زند → **پیامک به گوشی کاربر می‌رسد**
3. کاربر کد را **در چت Arena** می‌گوید؛ Arena همان را در `scripts/rasmio/otp.txt`
   روی شاخهٔ اجرا می‌نویسد؛ ربات هر ۱۰ ثانیه چک می‌کند (تا ۸ دقیقه)
4. ربات وارد می‌شود، برای هر شرکت صفحه + «شبکه ارتباطات» را باز می‌کند و
   HTML + همهٔ JSONهای شبکه + اسکرین‌شات را در artifact «rasmio-capture» می‌گذارد
5. Arena خروجی را با `gh run download` می‌گیرد، artifact را **حتماً حذف می‌کند**
   (دادهٔ خصوصی است — ریپو عمومی است) و بعد داده را وارد SRIP می‌کند

## نکته‌های امنیتی

- شمارهٔ موبایل و کد هرگز در لاگ چاپ نمی‌شوند (ماسک می‌شوند).
- artifact فقط ۱ روز عمر دارد و بعد از دانلود دستی حذف می‌شود.
- نشست (کوکی) رسمیو فقط داخل همان artifact است و جایی کامت نمی‌شود.
