# دادهٔ کمکی تاریخی روزنامهٔ رسمی — OCR عمومی

این پوشه **متن واقعی دریافت‌شده از یک مخزن عمومی ثالث** را نگهداری می‌کند، نه خروجی خزش مستقیم سایت روزنامهٔ رسمی و نه متن تصحیح‌شدهٔ انسانی.

منبع: https://github.com/Rasmio-com/OldRRK

نسخهٔ ثابت منبع: `f7296586b23671ddc296b0492ef70324c68b04c4`؛ مسیر `samples/OCR.Boxes.jsonl`. مجوز MIT و نام صاحب اثر در `LICENSE.source.txt` حفظ شده است. ناشر در README تصاویر اصلی را منسوب به `ocr.rrk.ir` می‌داند؛ این انتساب و اسکن‌ها را مستقلاً تأیید نکرده‌ایم.

## محتوای واردشده

- تمام **۱۰٬۰۰۰ ردیف نمونهٔ عمومی** پردازش شد.
- **۱٬۵۸۰ قطعهٔ متنی مرتبط با شرکت‌ها** بر اساس نشانه‌های لفظی ثبت شرکت/سهامی/مسئولیت محدود انتخاب شد. این عدد **تعداد شرکت یکتا یا تعداد آگهی کامل نیست**؛ یک باکس ممکن است ناقص یا شامل چند آگهی باشد.
- **۱۰ رابطهٔ پیشنهادی مدیریت تاریخی** فقط در موارد دارای عبارت صریح نام شرکت و مدیریت استخراج شد. این‌ها در فایل جدا، با شناسهٔ مشاهدهٔ مختص همان قطعه، قرار دارند؛ OCR نام‌ها و تطبیق هویت تأیید نشده و هیچ سمت فعلی را اثبات نمی‌کنند.
- سال‌های موجود در نام فایل قطعات منتخب: ۱۳۱۳ تا ۱۳۱۶. این‌ها سال‌های برگرفته از نام فایل منبع هستند، نه تاریخ انتشار مستقلاً تأییدشده.
- هیچ شناسهٔ ملی امروزی به شرکت‌های تاریخی نسبت داده نشده است؛ هیچ شخصی بر اساس تشابه نام ادغام نشده؛ گراف اصلی و پرونده‌های رسمیو تغییر نکرده‌اند.

## فایل‌ها

- `company-boxes.jsonl`: متن OCR پاک‌سازی‌شده، منشأ، هش، نام باکس‌ها و پرچم‌های محدودیت هر قطعه.
- `candidate-relationships.json`: ده رابطهٔ پیشنهادی و حل‌نشده؛ **گراف اصلی نیست**.
- `manifest.json`: تعدادها، شناسهٔ نسخه و blob منبع، اندازه و SHA256 فایل‌ها.
- `LICENSE.source.txt`: مجوز منبع با حفظ انتساب.

ارقام فارسی/عربی به لاتین و ی/ک عربی به فارسی یکسان‌سازی شده‌اند؛ اعداد مستقل ده‌رقمی از متن حذف شده‌اند. خطاهای OCR به‌صورت حدسی تصحیح نشده‌اند. تمام متن‌ها `fullNoticeVerified=false` و `ocrTranscriptionVerified=false` دارند.

ابزار بازتولید از ریشهٔ مخزن: `python3 scripts/rasmio/import-rrk-public-ocr.py`؛ GitHub CLI باید از قبل متصل باشد. ابزار، تطبیق blob در نسخهٔ ثابت، اندازه، هش Git و مجوز را پیش از ورود کنترل می‌کند. تکرار اجرا، محتوای متنی یکسان تولید می‌کند؛ زمان دریافت manifest تغییر می‌کند.
