# Phase 4 — Notification / Workflow / Approval / Integration / Import / Export

Baseline: `srip-starter-2_PHASE3_NETWORK_SEARCH_REQUIREMENT_SCORING_ANALYTICS_REPORTING_BASELINE.zip`

## Completed contracts

- Notifications: event-driven rule engine, condition evaluation, recipient resolution, channel preferences, priority/critical-only filtering, grouping, deep links, delivery logs, in-app/email/push providers, read/unread pagination, daily/weekly digest dispatch.
- Workflow: event triggers, conditions, actions, wait/resume, workflow approvals, rejection state, entity linking, transactional action/commitment/opportunity creation, audit and domain events.
- Approval: generic domain approval requests for sensitive relationship creation, strategic score changes, data sharing, export, permanent delete, and data import; requester/approver separation and authorization.
- Integration: OAuth, encrypted tokens, refresh rotation, organization authorization, sync audit/events, raw-body signed webhooks, timestamp replay protection, webhook persistence and idempotency.
- Import: CSV/XLS/XLSX upload, mapping, validation, duplicate detection, preview, explicit ApprovalRequest gate, import, report, completion event/audit.
- Export: CSV/XLSX/PDF/JSON, permission check, mandatory approved export request, export audit log, idempotency through the canonical API contract.

Frontend and AI were not modified.
