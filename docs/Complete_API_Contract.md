# Complete API Contract

See `api/API_CONTRACT.md`. Runtime OpenAPI is generated by the NestJS Swagger configuration at `/docs`.

## Phase 7 Core Domain endpoints

### Organizations
- `GET /api/v1/organizations`
- `GET /api/v1/organizations/:id`
- `POST /api/v1/organizations`
- `PATCH /api/v1/organizations/:id`
- `PATCH /api/v1/organizations/:id/archive`

### People
- `GET /api/v1/people?q=&organizationId=`
- `GET /api/v1/people/:id`
- `POST /api/v1/people`
- `PATCH /api/v1/people/:id`
- `PATCH /api/v1/people/:id/archive`

### Relationships
- `GET /api/v1/relationships?organizationId=&status=`
- `GET /api/v1/relationships/:id`
- `POST /api/v1/relationships`
- `PATCH /api/v1/relationships/:id`
- `PATCH /api/v1/relationships/:id/archive`
- `POST /api/v1/relationships/:id/recalculate-score`

All Phase 7 protected endpoints require authentication and permission checks. Relationship mutations require access to both organizations at the service layer.

## Phase 27 Reporting / Export

- `GET /api/v1/reports/relationship-health`
- `GET /api/v1/reports/relationship-risk`
- `GET /api/v1/reports/network`
- `GET /api/v1/reports/meeting`
- `GET /api/v1/reports/opportunity`
- `GET /api/v1/reports/project`
- `GET /api/v1/reports/company`
- `GET /api/v1/reports/executive`
- `GET /api/v1/reports/holding`
- `GET /api/v1/reports/executive-summary`
- `GET /api/v1/reports/:kind/export/csv`
- `GET /api/v1/reports/:kind/export/xlsx`
- `GET /api/v1/reports/:kind/export/pdf`
- `GET /api/v1/reports/:kind/export/json`

Report read requires `report.read`; exports require `report.export`. Export actions are logged in both `DataExportLog` and `AuditLog`.
