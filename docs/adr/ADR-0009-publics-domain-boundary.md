# ADR-0009: مرز دامنهٔ عموم‌ها (Publics)

- Status: Accepted
- Date: 2026-09-10
- Sprint: ۱

## Context
عموم‌ها (کاتالوگ، شناسنامهٔ سازمان، گروه‌ها، اعضا، پوشش، شکاف، رسانه) دقیق‌ترین ماژول دمو است اما **فقط در mock پیاده شده** (ممیزی ردیف ۱۷). سه سؤال مرز: (۱) همپوشانی با روابط — هر دو «سلامت/پوشش/ریسک» دارند؛ (۲) وابستگی به زیرساخت — `pathSuggestion` شکاف‌ها به `/network/graph` وابسته است؛ (۳) مرز MVP — هسته است یا گسترش دامنه؟

## Decision
1. Namespace فعلی `/api/v1/publics/*` حفظ می‌شود — طراحی درست است.
2. امتیازهای `coveragePct`/`power-interest` به `EntityScore` با `PUBLIC_GROUP`/`PUBLIC_MEMBER` (ADR-0006) منتقل می‌شوند.
3. هشدارهای عموم‌ها (شکاف بحرانی، عقب‌مانده، سررسید بازبینی) به `Alert` با `module: PUBLICS` (ADR-0007) منتقل می‌شوند.
4. کاتالوگ‌ها (`PUBLIC_CATEGORY_FA`…) و قالب‌های `PUBLICS_TEMPLATES` دست‌نخورده می‌مانند — منطق دامنهٔ معتبرند، نه اضافه‌بار.
5. تثبیت شبکهٔ روابط پیش‌نیاز تثبیت `pathSuggestion` است — صراحتاً ثبت شد.
6. مهاجرت به API واقعی (Sprint 2) پشت پرچم `FEATURE_PUBLICS` انجام می‌شود؛ تا آن زمان وضعیت «فقط دمو» در `module-status.md` شفاف است.

## Consequences
- ✅ مرز روشن؛ زیرساخت مشترک امتیاز/هشدار بدون کپی منطق.
- ⚠️ تا Sprint 2 دمو و production این ماژول از هم جدا هستند (ریسک ثبت‌شده، نه مغفول).
- Rollback: کد دمو دست‌نخورده می‌ماند.
