# ADR-0011: مرز هیئت‌مدیره، تحلیل راهبردی و دانش

- Status: Accepted
- Date: 2026-09-10
- Sprint: ۱

## Context
سه ماژول بزرگ دیگر فقط در mock زنده‌اند (ممیزی ردیف ۲۰/۲۲/۲۴): گزارش هیئت‌مدیره (`/board/overview` — تجمیع سرمایهٔ رابطه)، تحلیل راهبردی (`/strategy/*` — نظریهٔ بازی‌های قطعی)، دانش (`/knowledge` — KB جدا از اسناد). هر سه از دادهٔ ماژول‌های Done تغذیه می‌شوند و منطق موتوری معتبر دارند.

## Decision
1. هر سه «گسترش دامنه» (نه هستهٔ MVP) هستند ← پشت feature flag (`FEATURE_BOARD`, `FEATURE_STRATEGY`, `FEATURE_KNOWLEDGE`) قرار می‌گیرند — بدون حذف کد.
2. گزارش هیئت‌مدیره از `EntityScore` (ADR-0006) تغذیه می‌شود؛ هشدارهای مرتبطش در Sprint 2 به `Alert` با ماژول متناسب می‌نشینند.
3. مهاجرت به API واقعی در Sprint 2-3 پس از عموم‌ها (اولویت: عموم‌ها > راهبرد > هیئت‌مدیره > دانش) — موتور نظریهٔ بازی‌ها (PRNG بذردار) به‌صورت pure TS منتقل‌پذیر است.
4. تا مهاجرت، وضعیت «فقط دمو» در `module-status.md` شفاف می‌ماند.

## Consequences
- ✅ هستهٔ اصلی اول تثبیت می‌شود؛ هیچ کدی حذف نمی‌شود.
- ⚠️ سه ماژول تا Sprint 2-3 در production واقعی قابل استفاده نیستند (ریسک ثبت‌شده).
- Rollback: flag خاموش = مخفی، بدون حذف.
