## Cross-cutting
- Responsive: desktop, laptop, tablet, mobile browser
- Accessibility: keyboard, screen reader, contrast, focus, semantic HTML, ARIA, reduced motion, accessible forms/tables
- Localization: Persian/English, RTL/LTR, Persian/Gregorian dates, timezone and number formatting
- Web and mobile use the same API contracts and authorization rules.
