# SRIP Design System — Phase 24 baseline

## Tokens
- Color, spacing, typography, radius, shadow and motion tokens are centralized in the web/mobile UI foundations.
- Light/dark/system themes are represented in product settings.

## Accessibility
- Semantic landmarks and headings.
- Visible keyboard focus.
- Reduced-motion media query.
- Accessible form labels and status/error regions.
- Tables/lists must retain meaningful headings and labels.

## Responsive rules
- Desktop >= 1024px
- Tablet 768–1023px
- Mobile browser <768px
- No fixed-width critical workflows.

## Direction and language
- Default Persian/RTL presentation; English/LTR content must be supported by the i18n layer.
