# SRIP API Contract — v1 (canonical)

Base path: `/api/v1`. JSON over HTTPS. All authenticated routes require Bearer access token unless explicitly marked public.

## Envelope and headers
- Success: resource JSON; collection responses use `{items,nextCursor,total?}` where applicable.
- Error: `{code,message,requestId,details?}`.
- `X-Request-Id` is echoed/generated.
- `Idempotency-Key` is required for retry-sensitive mutations/import/exports where documented.
- Authorization is evaluated against the resource and organization scope; failures are fail-closed.
- Dates are ISO-8601 UTC.
- Soft-deleted records are never returned by default.

`/auth/login`, `/auth/logout`, `/auth/refresh`, `/auth/verify-email`, `/auth/forgot-password`, `/auth/reset-password`, `/auth/mfa/*`, `/sessions`, `/users`.

### Network
- `GET /network/graph` query: `organizationId,type,status,q,focus`
- `GET /network/path` query: `from,to,organizationId,mode=shortest|best`
- `GET /network/connectors`
- `GET /network/centrality`
- `GET /network/bridges`
- `GET /network/bottlenecks`
- `GET /network/single-points-of-failure`
All Network endpoints require `network.read` and organization-scope authorization.
### Intelligence / AI
- `GET /intelligence/relationship`
- `GET /intelligence/network`
- `GET /ai/status`
- `GET /ai/provider-health`
- `GET /ai/executive-brief?organizationId=&weekStart=`
- `POST /ai/query`
- `POST /ai/retrieve`
AI retrieval is permission-aware, audited, redacted and human-confirmation gated for write-like suggestions.
### Reporting / Export
`GET /reports/:kind`, `GET /reports/:kind/export/{csv|xlsx|pdf|json}`; export requires `report.export` and creates an export audit record.
### Privacy / Governance
`GET/POST /privacy/consents`, `POST /privacy/consents/revoke`, `GET/POST /privacy/requests`, `POST /privacy/requests/:id/{access|export|erase}`, `/privacy/lifecycle`, `/privacy/retention/*`, `/privacy/audit`.
### Data management
`POST /data/import/preview`, `POST /data/import/:id/approve`, `GET /data/import/:id/report`, `GET /data/quality`, `GET /data/duplicates`.
### Files
Upload validates size/MIME/extension/content, quarantines, malware-scans, stores privately with random keys and exposes only short-lived signed download URLs after CLEAN status.
### Admin
`/admin/overview`, users, organizations, tags, relationship-types, interaction-types, workflows, custom-fields, scoring-rules, notification-rules, ai-settings, integrations, audit.

## Pagination / filtering
List endpoints accept explicit `page|cursor`, `limit`, `sort`, `order`, and documented resource filters. Limits are server-capped.

## Contract governance
OpenAPI is generated by Nest Swagger at `/docs`; this Markdown is the source-aligned human contract. Breaking changes require a versioned migration note and compatibility window.

### Reporting / Export — canonical report kinds and formats
Report kinds are fixed and validated by the API:
- `relationship-health`
- `relationship-risk`
- `network`
- `meeting`
- `opportunity`
- `project`
- `company`
- `executive`
- `holding`
- `executive-summary`

Export formats are fixed and validated: `csv`, `xlsx`, `pdf`, `json`.

`GET /api/v1/reports/:kind` returns the report dataset. Export routes return a binary download with `Content-Disposition: attachment` and create both `DataExportLog` and `AuditLog(action=EXPORT)` records. Organization scope and ABAC authorization are evaluated before data retrieval and export.

The executive summary contract contains `summary`, `kpi`, `trends`, `risks`, `opportunities`, `recommendations`, and `supportingData`.

## Data Import / Duplicate Detection / Data Quality

### Import
- `POST /api/v1/data/import/preview` — multipart field `file`; body fields `entityType` (`ORGANIZATION|PERSON`), optional `organizationId`, optional JSON `mapping`.
- `GET /api/v1/data/import/:id/report` — returns persisted import summary and row-level validation/duplicate results.
- `POST /api/v1/data/import/:id/approve` — explicit approval; body `duplicateStrategy` (`SKIP|UPDATE|CREATE`).

### Quality
- `GET /api/v1/data/quality?organizationId=<id>` — latest persisted scoped snapshot, or a fresh scan when no snapshot exists.
- `POST /api/v1/data/quality/scan` — executes a scoped quality scan; body may contain `organizationId`.
- `GET /api/v1/data/duplicates?organizationId=<id>` — executes/returns duplicate metrics for the permitted scope.

Permissions: `data.import`, `data.import.approve`, `data.quality.read`, `data.quality.execute`.

## API Contract Hardening — Phase 30

- Collection GET responses are normalized to `{items,nextCursor,total}` when the handler returns an array; `page`, `cursor`, `limit`, `sort`, and `order` are accepted, with a server response cap of 200.
- Authenticated mutation endpoints require `Idempotency-Key` (minimum 16 characters) and persist a request fingerprint/replay record. Public authentication bootstrap endpoints are exempt because they establish authentication rather than mutate an authenticated resource.
- `X-Request-Id` and `X-Correlation-Id` are generated/echoed on every request.
- All Nest-handled errors use `{code,message,requestId,details?}`; early middleware failures use the same contract.
- Central output filtering removes credentials/secrets from serialized API responses.
- Swagger/OpenAPI is generated after the `/api/v1` prefix is applied, then augmented and validated at startup for pagination, idempotency, correlation/request IDs, security, standard error responses, and required canonical paths.
