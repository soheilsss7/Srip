# Build Plan

1. Foundation: repository, environments, Docker, CI.
2. Identity: OIDC, MFA, sessions, roles, permissions.
3. Core domain: organizations, people, relationships.
4. Interaction: calls, emails, notes, meetings.
5. Execution: actions, commitments, projects, opportunities.
6. Network: graph, paths, connectors, relationship health.
7. Intelligence: scoring, risk, recommendations.
8. AI: gateway, RAG, meeting brief/summary, next-best-action.
9. Integrations: Google/Microsoft calendar/email.
10. Mobile hardening, offline sync, push.
11. Observability, load/security tests, DR.
12. Production launch.
